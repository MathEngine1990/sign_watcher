# Файлы для этой папки

- `victory.mp3` — Успешное завершение уровня.
- `defeat.mp3` — Окончательное поражение.
- `chapter-complete.mp3` — Завершение главы, вместо обычной победы.
- `campaign-complete.mp3` — Финал всей истории, вместо обычной победы.
- `achievement.mp3` — Получено достижение.
- `unlock.mp3` — Открыта способность или новый режим.
- `record.mp3` — Новый рекорд.
- `reward.mp3` — Бонус подтверждён рекламной площадкой.

Эффекты подключены к игре.
