# Файлы для этой папки

- `click.wav` — Обычное нажатие кнопки.
- `select.mp3` — Выбор героя, облика, главы, уровня или режима.
- `open.mp3` — Открытие профиля, справки или окна.
- `back.mp3` — Закрытие окна и возврат.
- `start.mp3` — Запуск уровня.
- `pause.mp3` — Пауза.
- `resume.mp3` — Продолжение после паузы.
- `confirm.mp3` — Подтверждение действия, принятие соглашения.
- `unavailable.mp3` — Недоступное действие, если интерфейс допускает нажатие.

Эффекты подключены к игре.
