# Файлы для этой папки

- `wave-start.mp3` — Начало новой волны.
- `enemy-spawn.mp3` — Появление обычного врага, короткий общий звук.
- `sign-hit.mp3` — Снят знак с врага, но он ещё жив.
- `enemy-defeat.mp3` — Враг уничтожен.
- `cleanse.mp3` — Возвращение света после уничтожения, мягкий акцент.
- `hero-damage.mp3` — Потеря сердца.
- `low-health.mp3` — Переход к последнему сердцу.
- `projectile.mp3` — Выстрел Стрелка или босса.
- `split.mp3` — Делитель распадается на двух врагов.
- `rewrite.mp3` — Переписчик меняет знак.
- `boss-enter.mp3` — Выход босса.
- `boss-phase.mp3` — Переход босса в следующую фазу.
- `boss-defeat.mp3` — Победа над боссом.

Эффекты подключены к игре.
