Музыка бесконечного режима
Добавляйте композиции .mp3 в эту папку public/audio/music/endless.
Все композиции играют последовательно по имени и повторяются по кругу.
После добавления перезапустите npm run dev или выполните npm run build.
Не добавляйте оригиналы только в dist: эта папка перезаписывается при сборке.
